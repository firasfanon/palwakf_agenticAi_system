# Local Agent Console — عقد الواجهة

الواجهة ليست مبنية بعد في Foundation V1. Backend المحلي يجهز API أولي يمكن أن تستهلكه لاحقًا واجهة Flutter Windows Desktop أو Web محلية.

## الشاشات المخططة
1. Dashboard: الأدوار وحالاتها.
2. Task Intake: إنشاء مهمة مع مجال وأدلة وحدود.
3. Task Queue: انتظار / مقبول / مرفوض / يحتاج مراجعة.
4. Report Viewer: تقرير عربي وأدلة وسجل قرار.
5. Audit: كل عملية محلية وتوقيتها.

## محظورات الواجهة في V1
لا تعرض أزرار SQL، Publish، Deploy، Git commit، Delete source files، أو تعديل منصة.
