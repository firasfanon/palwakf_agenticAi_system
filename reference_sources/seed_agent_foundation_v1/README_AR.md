# حزمة تأسيس وكلاء PalWakf المحليين — v0.1

هذه الحزمة تتضمن خمسة ملفات تأسيسية مقترحة لفريق مساعدين ووكلاء متخصصين.

## ما هي هذه الحزمة؟

هي نقطة انطلاق لتقليل تفاوت جودة الجلسات، وحماية قرارات السيادة، ومنع العودة إلى `public` كمصدر بيانات أساسي، وتنظيم الانتقال لاحقًا إلى وكلاء محليين محدودي الصلاحية.

## قبل اعتمادها داخل المشروع

1. ضع الملفات تحت مجلد الوثائق المعتمد في مستودع PalWakf.
2. قارنها مع `PALWAKF_PLATFORM_COMPREHENSIVE_GUIDE.md`.
3. صحح أي تعارض لصالح المرجع الحاكم.
4. حدث `PALWAKF_STATE_SNAPSHOT.md` من آخر Baseline فعلي ونتائج البيئة.
5. ثبّت النسخة في Git مع رسالة واضحة.

## الملفات

- `PALWAKF_AGENT_CONSTITUTION.md`: قواعد حوكمة الوكلاء.
- `PALWAKF_AGENT_REGISTRY.yaml`: سجل الأدوار والصلاحيات والمخرجات.
- `PALWAKF_STATE_SNAPSHOT.md`: لقطة حالة تأسيسية تتطلب المطابقة.
- `PALWAKF_CURRENT_TASK.md`: أول مهمة معتمدة لتأسيس المرجع والوكلاء.
- `PALWAKF_AI_CONSTITUTION.md`: تعليمات مشتركة لأي مساعد يعمل على PalWakf.
