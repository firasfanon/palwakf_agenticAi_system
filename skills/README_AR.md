# Skills Foundation V1

الـSkill ليست دورًا ولا Prompt حرًا. هي إجراء مقيد قابل لإعادة الاستخدام.
لا تستخدم أي Skill حتى يتطابق الدور والمهمة ومستوى الاستقلالية والمدخلات والمخرجات مع السجل.

كل Skill يتضمن:
- هدف ونطاق ومحظورات.
- أدوار مؤهلة ومخاطر واستقلالية.
- مدخلات ومخرجات قابلة للتحقق.
- خطوات تنفيذ لا تكشف تفكيرًا داخليًا خامًا.
- دليل مطلوب وتصعيد.
- مثال واختبار قبول تصميمي.

لا يوجد في Foundation V2 runner ينفذ الـSkills أو أدوات. هذه عقود جاهزة للاختبار أولًا.
