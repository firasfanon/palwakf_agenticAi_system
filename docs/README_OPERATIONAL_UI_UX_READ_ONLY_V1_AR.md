# MEGA_BATCH_COMMAND_CENTER_OPERATIONAL_UI_UX_READ_ONLY_V1

## الغرض
تحويل Command Center من سطح تقني بسيط إلى لوحة تشغيل عربية RTL داكنة واحترافية، مستوحاة من المراجع البصرية المعتمدة، دون تحويلها إلى نظام تنفيذ وكلاء.

## نطاق التعديل المسموح
ثلاثة ملفات static فقط: `index.html`, `styles.css`, `app.js`.

## ما تعرضه
Dashboard، المهمة المعتمدة، الوضع السيادي، الوكلاء، الأدلة، المراجعات، الحوكمة، وصحة النظام.

## ما لا تضيفه
لا Routes، لا write methods، لا Model/Pilot execution، لا تعديل API أو task state أو DB أو platform أو Git أو deployment أو secrets أو memory.
