# UAT — التجربة النموذجية المحلية المحكومة V1

## قبول الدفعة الحالية
1. فحص تركيب Python وPowerShell.
2. التحقق من أن إعداد التجربة `enabled=false`.
3. التحقق من أن حالة التجربة تعرض `DISABLED_BY_DEFAULT`.
4. محاولة طلب مسودة نموذجية مع التجربة معطلة: يجب أن ترفض `403 MODEL_PILOT_DENIED` دون اتصال بـOllama.
5. محاولة استخدام مساحة عمل أخرى: يجب أن تبقى مرفوضة.
6. إبقاء مسارات التنفيذ العام غائبة.

## ليس ضمن UAT الحالي
لا يتم تشغيل Ollama، ولا تحميل نموذج، ولا إرسال Prompt، ولا إنشاء مسودة نموذجية.
