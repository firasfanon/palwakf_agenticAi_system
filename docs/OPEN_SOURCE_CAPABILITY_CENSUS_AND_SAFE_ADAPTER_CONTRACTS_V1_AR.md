# سجل القدرات مفتوحة المصدر وعقود المحولات الآمنة — V1

## الغرض

إنشاء سجل موحد للقدرات الخارجية المحتملة دون تنزيلها أو تثبيتها أو تشغيلها.

## القرارات

- **مرشح أولوية:** Tree-sitter، OpenTelemetry.
- **مرشح بعقد محجوب:** Semgrep، Gitleaks، Trivy.
- **مؤجل معماريًا:** Temporal، Prefect.
- **مراجعة ترخيص/خصوصية لاحقة:** Langfuse، Phoenix.
- **مرجعي فقط:** SWE-agent، Aider.

## قاعدة الدمج

لا تدخل الأداة الخارجية إلى النواة كسلطة مستقلة. يجب أن تمر عبر:

1. سجل القدرة.
2. عقد محول واضح.
3. بوابة تفعيل مسماة.
4. نطاق مشروع محدد.
5. مخرجات منقحة.
6. سجل دليل.
7. موافقة بشرية عند أي تنفيذ.

## حالة V1

هذه الدفعة لا تنشئ تنفيذًا للأدوات. عقود المحولات الخمسة معطلة صراحةً.
