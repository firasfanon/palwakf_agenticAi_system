# قبول وتشغيل الأدوات مفتوحة المصدر — الموجة الأولى V1

## الوظيفة

تحويل سجل القدرات إلى نظام قبول تشغيلي متدرج، دون تنزيل أو تثبيت أي أداة.

## الأدوات في الموجة الأولى

- Tree-sitter: قراءة فقط عند إثبات الوجود والنسخة والبصمة.
- OpenTelemetry: تتبع محلي فقط عند اكتشاف الحزمة أو Collector محلي.
- Semgrep: فحص قرائي يطلقه المستخدم بقواعد محلية فقط.
- Gitleaks: فحص أسرار قرائي يطلقه المستخدم مع حجب القيم.
- Trivy: يبقى في Readiness Hold حتى اعتماد قاعدة ثغرات محلية وسياسة تحديثها.

## الأدوات المؤجلة

Temporal وPrefect وLangfuse وPhoenix وSWE-agent وAider تبقى مؤجلة أو محجوبة وفق قرار السجل.

## Safe Process Broker

- argv ثابتة يحددها النظام.
- `shell=False`.
- لا أوامر حرة.
- نطاق داخل المشروع فقط.
- Timeout وحجم مخرجات محدود.
- بيئة منقحة.
- بصمة SHA-256 للملف التنفيذي.
- لا إعادة محاولة تلقائية.
