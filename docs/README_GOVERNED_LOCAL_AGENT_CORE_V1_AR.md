# Governed Local Agent Core V1

هذه الدفعة تبني سجل وكلاء محليين داخل المشروع، مرتبطًا صراحة بمساحة العمل وسياسة تلك المساحة.

- الوكلاء لا يملكون Shell أو Git أو قاعدة بيانات أو نشر أو شبكة خارجية.
- Ollama هو توافق إعداد فقط؛ لا يوجد اتصال نموذج ولا route لتشغيل نموذج.
- التحضير المحلي المحدد يحتاج فعلًا بشريًا صريحًا، ويُخزن محليًا داخل مساحة العمل مع hash chain.
- لا توجد ذاكرة مشتركة أو انتقال بيانات بين المساحات.
- لا يمنح Review Packet أي سلطة تنفيذ مستقبلية.
