# External Engineering Skills Reference Intake V1

## النطاق
استيعاب مرجعي محكوم لمستودع `addyosmani/agent-skills` داخل PalWakf Local Agents.

## القرار
يتم اعتماد المستودع كمرجع Skills Workflow فقط، لا كتثبيت مباشر.

## ما تمثله المهارات
- Define: توضيح المطلوب والمواصفة.
- Plan: تفكيك الخطة إلى مهام صغيرة.
- Build: مرجع تنفيذ مرحلي لاحقًا، غير مفعل الآن.
- Verify: فحص وتشخيص لاحق عبر بوابات مستقلة.
- Review: مراجعة جودة وأمن وتوثيق.
- Ship: إطلاق لاحق محجوب حتى بوابات تشغيل.

## الحدود
- لا git clone.
- لا npx skills add.
- لا plugin install.
- لا /build auto.
- لا Model/Pilot/Shell/Git/Code execution.
- لا DB persistence.

## الاستخدام الحالي
تظهر المهارات في `/agent-console/engineering-skills` وتربط Goal Planner وTask Drafts بمنهجيات عمل داخلية فقط.
