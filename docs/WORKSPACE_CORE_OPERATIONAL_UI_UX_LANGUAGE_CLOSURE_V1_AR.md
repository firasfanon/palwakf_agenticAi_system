# Workspace Core — إغلاق الواجهة التشغيلية واللغة V1

## الهدف
إغلاق مشكلة تجاوز القيم التقنية الطويلة داخل بطاقات `/workspaces` وتحويل العرض إلى واجهة عربية تشغيلية مستقرة، دون تغيير أي عقد Core أو API أو Policy Pack.

## النطاق
- تعديل طبقة العرض فقط: `index.html`, `styles.css`, `app.js`.
- توسيع اختبار Workspace Core ليتحقق من عقد العرض العربي ومن قواعد منع تجاوز النص.
- إضافة UAT بصري وتشغيلي محدود.

## ما لا يتغير
- لا تغيير لـ `store.py` أو `router.py` أو مسارات API.
- لا تغيير لسياسات `policy_packs` أو قيمها الداخلية.
- لا إنشاء أو حذف أو تفعيل Workspace.
- لا إضافة route للكتابة أو التنفيذ أو تشغيل النموذج.

## عقد العرض
- القيم الداخلية الخام تبقى مصدر الحقيقة وتظهر فقط ضمن قسم تقني مطوي عند طلب المراجع.
- البطاقات تعرض تسميات عربية تشغيلية، ولا تعتمد على عرض Enum الخام الطويل.
- النصوص الطويلة يجب أن تستخدم `overflow-wrap:anywhere` و`word-break:break-word` ضمن حاويات مرنة.
- يجب أن تبقى الشبكة قابلة للاستجابة: عمودان عند العرض المعتاد وعمود واحد عند الشاشات الأضيق.
