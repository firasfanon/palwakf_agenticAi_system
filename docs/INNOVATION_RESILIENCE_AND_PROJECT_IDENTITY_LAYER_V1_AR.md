# طبقة الابتكار والمرونة وهوية المشروع V1

## الغرض

تحويل الإبداع ومقاومة عيوب الوكلاء إلى عقود تشغيلية محلية قابلة للتدقيق، دون فتح نموذج أو تنفيذ أو أدوات كتابة.

## المكونات

1. مراجعة ابتكارية تحضّر ثلاثة بدائل: محافظ، متوازن، وابتكاري.
2. ملخص قرار يعرض الافتراضات والأدلة والمخاطر والشك دون سلسلة التفكير الداخلية الخام.
3. حارس انحراف السياق بمقارنة حتمية بين الهدف والإجراء المقترح.
4. Attempt Limiter يمنع حلقات الفشل ويطلب التصعيد البشري بعد ثلاث إخفاقات متتالية.
5. Checkpoint وصفي يحفظ metadata الحالة فقط، دون نسخ المصدر أو قاعدة البيانات.
6. ملف هوية تصميم لكل مشروع مع بصمة SHA-256.
7. فحص Anti-Similarity حتمي بمقارنة الألوان والخطوط والكثافة والتنقل والبطاقات والزوايا وبصمة التخطيط.
8. قمرة تشغيل تلخص الهدف والمرحلة والمراجعات والتحذيرات والهوية.

## التخزين المحلي

تُضاف الملفات التالية تحت `runtime_state/operational_core_v1`:

- `innovation_reviews.json`
- `resilience_state.json`
- `project_identities.json`

ولا توجد كتابة في قاعدة بيانات أو مصدر المشروع وقت التشغيل.

## الحدود

- Model inference: NONE
- Pilot: NOT EXECUTED
- Shell/Git/Code execution/Self-Apply: BLOCKED
- Vector DB/ChromaDB: NONE
- Automatic retry: FALSE
- Checkpoint: METADATA ONLY
