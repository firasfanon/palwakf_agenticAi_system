# Command Center — إغلاق الاستجابة للشاشات الضيقة V1

**نوع الدفعة:** واجهة ثابتة فقط.

تعالج هذه الدفعة قص العرض الأفقي في Command Center عند العروض الضيقة، دون تغيير API أو صلاحيات أو مسارات تنفيذ.

- تحويل الشريط الجانبي إلى Drawer على الشاشات الأقل من 900px.
- إضافة Scrim للإغلاق باللمس وEscape.
- منع overflow الأفقي العام وإجبار main/view/grid على `min-width: 0`.
- الحفاظ على عقد Command Center: قراءة ومراجعة فقط.
