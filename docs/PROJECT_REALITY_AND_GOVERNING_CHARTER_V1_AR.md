# PROJECT REALITY AND GOVERNING CHARTER V1

## التعريف الرسمي

الحقيقة العملية لمشروع PalWakf Local Agents هي:

**Governed Local Engineering Agentic Platform** — منصة هندسية محلية محكومة تساعد مطور نظم المعلومات على تحويل الأهداف العالية المستوى إلى خطط وأدوات ومراجعة بشرية، مع بقاء التنفيذ مؤجلًا ومشروطًا بتفويض مستقل.

## ما هو المشروع؟

المشروع ليس مجرد Chat، وليس مجرد واجهة أدوات، وليس نموذجًا محليًا فقط. هو نواة منصة هندسية محلية:

1. تستقبل هدفًا عالي المستوى.
2. تحوله إلى خطة مشروع.
3. تربط الخطة بالأدوات والمساعدين المناسبين.
4. تعرض المخاطر والحدود.
5. تمر عبر Human Review Gate.
6. لا تنفذ إلا عبر بوابات مستقبلية مستقلة.

## المبادئ الحاكمة

- Human Authority: المستخدم صاحب القرار النهائي.
- Goal-to-Plan First: الهدف يتحول إلى خطة قبل أي إجراء.
- Tool Contracts: كل أداة لها عقد وحدود.
- Local Sovereignty: لا تسريب كود أو وثائق أو أهداف إلى الخارج.
- Auditability: أي تنفيذ لاحق يجب أن يكون قابلًا للتدقيق.
- No Self-Apply: الوكيل لا يطبق على نفسه.
- No Hidden Execution: لا Shell/Git/Model/Pilot/Code execution مخفي.

## ما لا تفعله هذه الدفعة

- لا تشغل نموذجًا محليًا أو سحابيًا.
- لا تبدأ Pilot.
- لا تنفذ Shell أو Git.
- لا تنفذ كودًا.
- لا تحفظ في قاعدة بيانات.
- لا تبني مشروعًا جديدًا.
- لا تفعل self-apply.

## علاقة هذه الوثيقة بخارطة الطريق

هذه الوثيقة تربط المراحل المقبولة:

- Frontend Operational Workspace
- Backend/Frontend Alignment
- Task Draft Backend Binding
- Task Draft Review Flow
- Codebase Understanding Read Model
- Local Model Strategy Matrix
- Goal-to-Plan Tool Selection

وتمنع القفز إلى التنفيذ قبل بناء:

- Project State Manager
- Audit Trail
- Model Runtime Readiness Gate
- Controlled Local Model Pilot
- Execution Authorization Gate
