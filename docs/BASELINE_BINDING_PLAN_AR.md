# خطة ربط خط الأساس قبل Candidate التطبيقي

## الهدف
لا نبني Patch على افتراضات عن مصدر المشروع. نلتقط بصمات الملفات الحاكمة ونثبت وجود المساحات الأربع وحالة Pilot المعطلة.

## خطوات البوابة
1. فحص صياغة الحزمة نفسها.
2. تشغيل جرد خط الأساس للقراءة فقط.
3. مراجعة `BASELINE_MANIFEST` و`BASELINE_RESULT=PASS`.
4. عندها فقط يُنشأ Candidate تطبيقي واحد موحد، بأسماء الملفات وبصماتها الدقيقة، ثم Syntax + Preflight + WhatIf ثم Apply مستقل.

## ضمانات الجرد
الجرد يكتب تقريرًا داخل `%TEMP%` فقط. لا يغير ملفات المشروع ولا يتصل بـOllama ولا يشغّل نموذجًا.
