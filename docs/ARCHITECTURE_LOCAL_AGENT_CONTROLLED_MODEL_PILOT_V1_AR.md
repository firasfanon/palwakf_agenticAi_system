# معمارية التجربة النموذجية المحلية المحكومة V1

## الهدف
إضافة طبقة **استعداد تقني** لتجربة نموذج محلي واحد لاحقًا، دون تشغيل النموذج في هذه الدفعة ودون فتح أي صلاحيات تنفيذية.

## النطاق الثابت
- مساحة العمل الوحيدة: `palwakf_government`.
- الوكيل الوحيد: `task_planning_runbook_agent_v1` (وكيل تخطيط المهام وإجراءات التشغيل).
- نوع المخرج الوحيد عند تفعيل مستقل مستقبلاً: مسودة خطة/إجراء (`draft_runbook`) للمراجعة البشرية.
- المزود: Ollama محلي فقط على `127.0.0.1:11434` أو `localhost:11434`.

## خارج النطاق
لا يوجد Shell، أو Git، أو تعديل ملفات، أو تعديل قواعد بيانات تشغيلية، أو نشر، أو شبكة خارجية، أو وصول متبادل بين مساحات العمل، أو ذاكرة مشتركة.

## المصطلحات
- **Pilot / تجربة محكومة:** تشغيل محدود جداً يُقاس ويُراجع قبل التوسع؛ هذه الدفعة لا تشغله بل تُبقيه معطلاً افتراضياً.
- **Model Adapter / موائم النموذج:** طبقة اتصال مقيدة تتحدث فقط مع Ollama المحلي؛ لا تمنح الوكيل أدوات نظام.
- **Draft / مسودة:** نص مقترح لا يطبق أي تغيير ولا يمنح موافقة تنفيذ.
- **Human Review / مراجعة بشرية:** اعتماد شخص مخول للمخرج قبل أي قرار لاحق.
- **Loopback / اتصال محلي راجع:** اتصال من الجهاز إلى نفسه فقط (`127.0.0.1` أو `localhost`).
