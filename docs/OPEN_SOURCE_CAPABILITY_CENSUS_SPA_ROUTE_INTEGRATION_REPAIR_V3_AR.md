# إصلاح دمج صفحة القدرات مفتوحة المصدر داخل SPA — V3

## سبب الإصلاح

كان Backend API والسجل متاحين، لكن مسار:

`/agent-console/open-source-capabilities`

يصل إلى SPA العام. ولأن React Router الحالي لا يسجل المسار، ظهرت صفحة «الصفحة غير موجودة».

## الإصلاح

- إضافة Route Extension ثابتة ضمن `frontend/dist`.
- تحميل سجل القدرات والعقود والحدود من API الحالي.
- استبدال صفحة Not Found على هذا المسار فقط.
- إضافة رابط تنقل غير تنفيذي إلى بعض أسطح التشغيل.
- عدم تعديل Router الخاص بـReact أو إعادة بناء المشروع عبر npm.
- عدم تعديل Backend أو `app.py`.

## الحدود

لا تنزيل، لا تثبيت، لا تشغيل ماسحات، لا Shell، لا Git، لا Model inference.
