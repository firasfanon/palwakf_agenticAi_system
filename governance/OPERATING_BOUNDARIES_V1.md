# حدود التشغيل — V1

1. كل Agent محلي في هذه النسخة يعمل قراءة وتحليلًا فقط.
2. لا SQL، لا اتصال Supabase، لا تنفيذ Flutter، لا Git write، لا نشر.
3. أي مهمة تُنشأ محليًا تحتاج مصدر دليل ومجال نظام وحدود ممنوعات.
4. Back-end يعمل على `127.0.0.1` فقط.
5. تفعيل `ALLOW_AGENT_EXECUTION` لا يتم ضمن V1؛ يحتاج قرارًا مستقلًا ودليل قبول.
6. كل تقرير يخرج إلى `output/` مع سجل Audit محلي.
7. المراجع المستوردة من `palwakf` تقرأ ولا تُعامل كحالة حية ما لم تقترن بدليل حديث.
