# Model Output Acceptance Policy V1

لا يقبل مخرج النموذج إلا إذا:

- احتوى المفاتيح الإلزامية فقط.
- كان ASCII Key/Value فقط.
- أشار إلى Evidence IDs موجودة في الـManifest.
- لم يدع حالة حية.
- لم يقترح أوامر أو SQL أو Git أو نشر أو أسرار.
- لم يخرج خارج القيم المسموحة.

فشل العقد لا يعني فشل المهمة؛ يعني فقط أن مخرج النموذج غير صالح ويحتاج مراجعة أو تحسيناً منضبطاً.
