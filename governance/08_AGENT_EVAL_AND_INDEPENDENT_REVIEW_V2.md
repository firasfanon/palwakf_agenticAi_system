# Agent Evals and Independent Review V2

## Evaluation principle
Agents must be tested with positive and negative cases before gaining authority.
A passing free-form answer is insufficient.

## Independent review
High-risk work requires separation:
- executor,
- reviewer against specification,
- negative/security tester,
- coordinator/human acceptor.

## V2 baseline
Only evaluator design exists. No V2 role has passed the expanded evaluation suite yet.
