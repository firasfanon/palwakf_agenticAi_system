# CHANGELOG — Foundation V2

## Added
- Agentic Operating System governance layer.
- Roles expanded to product, architecture, QA/security and release disciplines.
- Skills Registry and per-skill contracts.
- Task lifecycle, risk, autonomy, approval, evidence, memory and learning registers.
- Prompt Injection and data classification policies.
- Workspace lock and tool-gateway contracts.
- Evals scaffolding.
- Safe installation and static validation scripts.

## Changed
- All current and future roles are bounded by `L0_READ_ONLY` / `L1_PLAN_ONLY` by default.
- `coding_builder` is a planning-only role until an isolated worktree admission batch is accepted.
- `tester` is a test-plan-only role until a command-whitelist admission batch is accepted.

## Not changed
- No current agent was promoted.
- No platform code, database, storage, Git, deployment, or external service was modified.
