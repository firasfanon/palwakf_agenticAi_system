# Agent Evals V2

هذه الحالات اختبارات قبول وتصعيد، وليست أوامر تشغيل.
لا يترقى دور إلا بعد وجود runner آمن ومدخلات متوقعة ومخرجات ممنوعة ومراجع بشرية.

المطلوب في كل Eval:
- السيناريو والمدخلات.
- السلوك المتوقع والممنوع.
- الدور/المهارة المسموحان.
- نوع الدليل.
- قرار Passed/Failed/Needs Improvement.
- Learning Candidate محتمل عند الفشل.
